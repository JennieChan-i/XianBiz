# 纤商使用帮助

## 开始经营
首次进入时填写店铺名称、启用日期与默认库存阈值。软件没有账号和登录页。店铺资料、数据库与商品图片只保存在本机数据目录。
先录入供应商，即可采购开单。首次进货在采购单中点击“新增商品并采购”，填写款号、名称、颜色尺码、本次件数和采购单价，保存后自动加入当前单据；后续补货直接选已有商品。客户按需要建档。可在系统设置下载 Excel 期初模板，预览通过后确认导入。金额按模板要求填写整数分。

## 商品与扫码
商品资料中填写款号、名称、默认批发价，使用逗号分隔颜色和尺码生成矩阵；无尺码可留空尺码输入。条码不是必填。
普通新增商品只建立档案，不增加库存，也不要求填写期初件数。开始使用软件前已有存货时，勾选“同时录入期初库存”；新SKU的期初件数默认空白，必须逐行填写，没有库存请明确填写0。采购中新建商品只填写本次采购件数和进价，不录期初库存，避免重复入库。保存后如发现期初件数或成本录错，且该SKU尚未发生后续业务，可在商品编辑表格点击“期初更正”，填写正确数量、单位成本及原因。原始记录保留，系统追加更正流水。已有确认订单、后续库存流水或盘点记录后，期初更正会锁定，库存通过采购、销售或盘点处理。
保存后打开详情上传图片，第一张默认主图，可将附图设为主图。图片自动压缩并进入完整备份。
USB 扫码枪设置为键盘输入并以 Enter 结束，在开单搜索框扫码即可加入。没有条码时可用款号、名称搜索或矩阵选货。

## 销售与预订
在销售开单中选择客户、添加商品数量、修改成交价，选择直接交付或预订。匿名散客必须直接全部交付并全额结清。
确认预订单只自动预留当时可用库存，不扣减账面库存、不形成收入或应收。收定金记预收，实际交付后才结转抵扣应收。
分批交付在订单详情登记每次 SKU 数量。补货不会自动分给历史欠货；请在订单详情点击手动分配补货。强制出库需确认风险并填写原因，可能挪用其他客户预留并形成负账面库存。
负库存出库优先最近有效成本；无历史价时必须手工填写暂估成本。后续入库按顺序清算差价，详情保留原始成本和调整记录。
开单内容自动暂存在本机浏览器。暂存不记账，提交成功后清理；可使用确认并新建下一单连续开单。

## 采购与运费
采购必须关联供应商。预订采购不增加库存，实际收货才形成库存与应付。分批收货在详情登记。
采购单内保存新商品后，商品资料中即可查到该款。尚未提交或取消当前采购单会保留商品档案，但未收货不会形成库存或应付；后续可直接选择该商品继续采购。
未收齐时可终止剩余。已有收货的主状态保持部分收货，并标记剩余终止；已收货和已付款历史不会删除。
采购运费单独记经营费用，不计入 SKU 成本。采购货款进入存货价值，不应重复手工登记为费用。

## 收付款与手动核销
一笔实际资金流水可以有现金、微信、支付宝、银行转账等多个渠道。请选择待核销债项并填写各自金额，支持同时核销多笔订单和期初欠款。
未核销资金保留为预收/预付。手动核销只分配余额，不重复登记现金。往来详情可以分别查看债项、贷项和核销记录。
退回预收付或退货退款时，必须明确选择可退贷项，分配合计等于实际退款金额。已生效资金不得直接修改日期，错误使用冲正保留原记录。

## 退货、换货和纠错
订单详情选择退货/换货，从原实际履约中填写可退数量。销售可售退货恢复库存，不可售退货计库存损失，不再重复登记费用。
可同时选择其他款式、颜色、尺码换货，新单与退货保持关联。价差在往来中手动核销、退款或补款。采购退货需有未被预留的可用库存。
整单错误可用整单冲正，并填写原因。所有纠错按实际操作时间追加记录，保留原单和原生效日期。

## 库存盘点与报废
允许边营业边盘点。每个 SKU 实物点数后立即记录实盘数量及当时账面基准。点数期间若有无法确定先后的实物移动，请重新清点。
确认盘点时只调整差额，记录后正常发生的出入库不会被覆盖。未记录 SKU 不按零库存处理。若盘亏会占用订单预留，默认先处理预留；必要时可明确确认盘亏风险，系统会记录预留减少和负库存损耗片段。
报废填写 SKU、件数及原因，计入库存损益，不应再次登记为经营费用。

## 报表与打印
销售收入按实际交付日、资金按实际收付日、费用按归属日、库存损益按确认日。退货与成本校正列入实际调整日，关联原订单。简化经营利润是管理口径。
订单详情提供 A4 打印/保存 PDF。浏览器打印对话框中选择打印机或另存为 PDF，不支持热敏小票。
Excel 导出包含经营明细，用于查阅留存。Excel 不能代替完整迁移备份。

## 手动备份与恢复
在系统设置的备份与恢复中创建完整备份，并将 ZIP 保存到另一磁盘或移动存储设备。软件不做定时自动备份。
完整备份包含 SQLite 数据库、商品图片、配置、版本及校验清单。数据库通过 SQLite Backup API 一致性快照生成。
恢复前确认选择正确文件，校验通过后替换当前数据，并保存恢复前保护副本。更换电脑时先安装纤商，再恢复完整备份。
程序安装目录与用户数据分离，升级或卸载程序不会主动删除 LOCALAPPDATA/XianBiz 经营数据。操作前仍建议手动备份。

## 启动与退出
双击桌面纤商图标启动；本地端口动态选择，只允许这台电脑访问。重复启动会打开已运行实例。
右上角安全退出会停止本地服务，可以随后关闭浏览器页。关闭浏览器标签页不会自动结束服务，请使用安全退出。
如果出现错误，保留输入并重试；若持续失败，查看系统设置中的本机目录和 xianbiz.log，再联系维护人员。
