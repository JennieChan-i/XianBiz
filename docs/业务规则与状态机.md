# 业务规则与状态机

以下是对审查文档“拟定最小规则”的工程解释，并非新增用户决策。所有金额为整数分，件数为整数；服务端校验，BEGIN IMMEDIATE 原子提交，操作号与请求摘要共同幂等。

## P0-01 履约、预收预付和核销

确认订单仅形成合同与预留。销售交付、采购收货分别生成债项。收款/付款只生成一笔资金主流水及渠道拆分，未分配部分作为预收/预付。核销只增加分配明细，不重复发生现金。订单指定定金在该订单履约时生成可追溯的预付款结转分配；其他余额只手工选择债项。期初债项独立存在。退货生成贷项，先抵原单剩余债项，剩余可退款或核销其他债项。匿名散客必须在一个事务内全部交付且全额收款。

## P0-02 预留与强制挪用

SKU 库存有符号，普通可分配量 max(0,库存-预留)。新确认订单只自动预留当时可用量；旧欠货存在时返回提示。收货不为旧欠货自动预留。手动分配检查可用量。强制交付必须提供风险确认和原因，先消耗自己的预留，再使用空闲库存，再按预留明细时间顺序减少受影响订单的预留；每笔记录受影响订单和原因，最后扣库存。预留不能大于 max(库存,0)。

## P0-03 移动平均与负库存成本

正库存保存数量、总价值（分）和最近有效单位成本。分摊采用整数四舍五入，最后一笔出库取剩余价值，避免尾差。负库存不能参与普通平均分母。超过正库存的每笔销售冻结暂估价，优先最近有效成本，无历史成本则必须手工输入。后续采购按负库存片段的先后清算；差价只影响尚未退回部分的销售成本，已退回部分按可售/不可售分别调整库存价值或损耗。全部调整保留原履约关联。剩余正库存才按移动平均累加价值。采购运费单独为费用。

盘盈和可售退货也会减少账面负数，必须先消减尚未清算的负库存片段；这部分用该笔入库成本清算，防止后续采购重复清算。采购退货按当前移动平均减少库存，货款差额列库存损益；禁止无库存强退采购货品。普通报废不强制占用其他订单预留。盘亏超出可用量时默认拒绝；老板明确确认风险后可减少相关预留并记录负库存损耗片段，后续补货差价进入库存损益。

## P0-04 营业中盘点

每条实盘记录在服务端提交瞬间捕获 ledger_id 和账面基准，用户需在实点后立即记录。确认差额 = 当时实盘数量 - 当时账面数量；确认时库存 = 当前库存 + 差额。此后流水不被覆盖。重复保存实盘值重新捕获时点；客户端过期基准可拒绝要求重盘。盘点确认写入实际确认时间。该语义要求点数与记录之间没有未记录实物移动；无法判定先后须重新清点。

## P0-05 部分终止

销售主状态：草稿、已确认待交付、部分交付、已完成、已取消。采购主状态仅待收货、部分收货、已收齐、已取消。订单独立 remaining_terminated 标记。无履约全取消；部分履约终止仍保持部分状态并展示“剩余终止”。释放预留，未履约余量不再允许交付。退货不抹掉履约事实；收付款状态独立计算。

## P0-06 历史日期与跨期调整

库存/资金发生时间只由本地服务生成；不接收改写原时间字段。费用允许选择归属日。退货、成本差异、冲正均追加当日流水，关联原记录。报表按发生日分别列收入、原始销售成本、成本校正、退货、库存损益、经营费用；简化利润不宣称法定会计净利润。

## 其他约束

### 期初件数与初始录入纠错（2026-10-17）

普通建档不录入库存和成本；选择期初库存录入时，新SKU的期初件数默认空白且必填，0为有效值；前后端均拒绝缺失、空值、负数及非整数，Excel期初导入也须明确填写件数。

首次进货可在采购开单内新增商品，填写本次采购件数和进价，建档保存后自动带入当前采购单；此时商品库存和成本均为0，未收货不产生库存、应付或资金流水。采购确认直接收货或后续分批收货时，按实际收货件数入库并形成应付。补货复用原商品及SKU，不重复建档。取消或离开采购单保留已建商品档案。采购内建档不提供期初录入，避免同一批货重复增加库存。

商品编辑表格的库存与成本只读，未发生后续业务的SKU提供独立“期初更正”入口。更正须填写目标件数、单位成本和原因，并检查打开时的数量、库存价值及单位成本快照；追加当前时间的期初差异流水和操作历史，不修改原始流水，不计入经营损益。该SKU已有非草稿订单引用、后续库存流水或实盘记录后锁定期初更正；正常库存变化继续通过业务单据和盘点处理。

已引用主档仅停用，订单保留名称价格快照。草稿仅本地暂存不记账。单据无附件，商品图片本地压缩。备份数据库、图片、设置、格式版本和 SHA256 清单；用 SQLite Backup API 获取一致性快照，备份期间统一写锁。恢复先校验路径、哈希、数据库完整性和外键，然后保存恢复前完整保护副本，在排他写锁内替换数据。仅手动触发备份，不设定时任务。

仅监听 127.0.0.1；校验 Host、Origin、Fetch Metadata、写请求随机令牌；无 CORS 通配，无账号。动态端口、Windows 文件锁单实例、桌面启动与安全退出。安装升级只替换程序，数据位于 LOCALAPPDATA/XianBiz。
